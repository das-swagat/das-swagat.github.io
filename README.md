# Swagat Das — Research Portfolio

Static GitHub Pages portfolio for Swagat Das.

## Files

- `index.html` — complete single-page portfolio, styles, interactions, and Google Scholar chart
- `assets/Swagat_Das_Resume.pdf` — current two-page resume used by the view and download buttons

## Publish

Upload the contents of this folder to the root of the `das-swagat.github.io` repository and commit the changes. GitHub Pages will deploy the updated site automatically.

## Update Google Scholar metrics

In `index.html`, find the JavaScript object named `scholarStats` near the bottom of the file and update:

- `totalCitations`
- `hIndex`
- `i10Index`
- `citationsSince2021`
- `yearlyCitations`

## Update the resume

Replace `assets/Swagat_Das_Resume.pdf` with the new PDF while keeping the same filename. The website links will continue to work without HTML changes.
