# Swagat Das — Research Portfolio

Personal academic and professional portfolio hosted with GitHub Pages.

**Live website:** [https://das-swagat.github.io](https://das-swagat.github.io)

The live homepage is controlled by the root `index.html`. The `assets/` folder contains the resume used by the site.

## Reusable portfolio template

A sanitized academic, professional, and research portfolio template is included in [`portfolio-template/`](portfolio-template/). It contains placeholders rather than personal names, institutions, links, publications, metrics, projects, or contact details.

The template folder does **not** affect the live personal website because GitHub Pages continues to load the root `index.html` for the homepage.

### Easiest way to use it

1. Download [`academic-professional-research-portfolio-template.zip`](academic-professional-research-portfolio-template.zip).
2. Extract the ZIP.
3. Create a new GitHub repository.
4. Upload the extracted files to the root of that repository.
5. Follow the detailed instructions in [`portfolio-template/README.md`](portfolio-template/README.md).
6. Enable GitHub Pages from the new repository's `main` branch and `/ (root)` folder.

### Using a fork

A GitHub fork copies this entire repository, including the personal website. After forking, use only the contents of `portfolio-template/` for the new site: move those files to the fork's root and remove the original personal `index.html` and `assets/` folder.

Exact command-line steps and customization instructions are provided in the template README.
